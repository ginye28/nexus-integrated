> 아래는 기록·실측으로 확인된 사실만 쓴 초안입니다. 본인 말투로 다듬어 이력서에 붙여 넣으세요.

**NEXUS WORK — AI 기반 보안 관제·자동 대응(SOAR) 사내 포털 방어 프로젝트**
- **기간**: 2026.10 ~ 2026.11 (4인 팀, 최종 발표 11/6) — 통합 환경 개인 고도화 11/9~11/10
- **역할**: 팀장 · 자동화·상황판(n8n) 담당 — 탐지된 공격이 차단·알림·기록으로 자동 이어지는 n8n 대응 워크플로 설계·구현, 공격 시연·통합 점검 주관
- **사용 기술**: Python(Flask), n8n, Graylog2, Wazuh, pfSense(HAProxy·pfBlockerNG)·Suricata·ntopng, MySQL, Docker Compose, Groq LLM API(openai/gpt-oss-120b), Discord Webhook
- **개요**: 사내 포털(그룹웨어·ERP·AI 챗봇)에 대한 공격을 Graylog·Wazuh 로 탐지하고, n8n 이 티켓·계정 조치·알림을 자동 수행하며, AI-XDR 이 위험도를 판정해 관리자 승인 시 IP 를 차단하는 파이프라인

**핵심 성과**
- n8n 자동 대응 워크플로 구현: 계정 잠금·세션 종료(기본 dry-run, live 지정 시에만 실행, 조치 후 재조회로 결과 기록)와 티켓 4종(침해·차단·이상 징후·오탐 해제) — R1~R12 목업 13건 분류 **13/13 일치**
- 모의 공격으로 네트워크 경계의 **관리 포트 4종(n8n·Graylog·DB·Ollama) 외부 노출을 발견**해 방화벽 조치 유도
- 보안모드 토글 3경로(웹·스크립트 2종) 상태 불일치 버그를 단일 기준으로 통합 — 팀 저장소 **PR #28 병합(+209/−82)**
